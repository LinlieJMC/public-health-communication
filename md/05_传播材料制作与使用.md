## 一、传播的发展简史与概念

### 概念｜P5

健康传播材料是健康信息的载体，是健康传播活动常用的辅助手段和策略，旨在配合活动的开展，向目标人群传递与传播活动主题相关的健康知识和技能，让目标人群对健康主题有一个较为全面的认识，提升目标人群应对和处理该健康问题的能力。

- 人际传播可不使用传播材料。

### 现代健康传播的常用活动形式｜P6

| # | 形式 | 具体方式 |
|---|---|---|
| 1 | 人际传播 | 群体：“大课堂”、培训/讲座、讨论、同伴教育、就诊过程中的教育与咨询；个体：入户指导、咨询、讲座 |
| 2 | 传播材料 | 个人使用：书刊、小册子、折页、传单；群体使用：板报、招贴画、标语、横幅、电子显示屏、DVD、录音带 |
| 3 | 大众传播 | 大众传媒：广播、电视、报纸、杂志、电影；社区活动：民俗活动、地方戏剧、小品、歌曲 |
| 4 | 新媒体 | 微博、微信、手机短信、手机 APP、可穿戴设备、门户网站、短视频、音频网站 |

### 分类｜P7

| # | 类别 | 举例 |
|---|---|---|
| 1 | 平面传播材料 | 海报、折页、小册子、图书等 |
| 2 | 音频传播材料 | 广播节目、音频网站等 |
| 3 | 视频传播材料 | 电视节目、电影、短视频等 |
| 4 | 实物类传播材料 | 以实物为载体 |

- 传播场景：大众媒介、新媒体、人际交流、全媒体。

## 二、各类材料的特点

### 平面传播材料｜P8–P12

| 类型 | 特点 |
|---|---|
| 海报与招贴画 | 由少量文字和较为突出的主题图构成，用于唤醒人们对健康问题的关注。优点是设计感强，视觉冲击力强，有吸引力，制作快捷，成本相对较低；缺点是对设计要求较高，信息量少 |
| 单页 | 印有健康信息的单页纸，只围绕一个主题展开叙述，信息比较简单，主要由文字和少量插图组成。优点是设计简单、制作快捷、成本低廉；缺点是不易保存，吸引力差。最适用于时间紧、任务急、大批量发放时使用，如发生突发公共卫生事件时 |
| 折页 | 正反面都印有健康信息的单页，通常为彩色印刷，常见形式有二折页和三折页。特点是设计精美、图文并茂，有较强的吸引力；内容板块清晰，信息简单明了；便于携带和保存；设计要求、制作成本显著高于单页 |
| 小册子（手册） | 介于折页与图书之间的一种健康科普读物，就某一健康主题或疾病问题进行系统、全面的阐述。特点是信息量大、内容系统完整，图文并茂、可读性强、便于携带，受众可以长时间、反复阅读，有保存价值；缺点是对目标人群的阅读理解能力有较高要求，内容编写、设计制作的成本较高 |
| 报纸 | 纸媒代表，便于携带，曾经是新闻的主要来源 |
| 杂志 | 固定出版，读者群固定，可承载较多信息内容和形式 |
| 图书 | 内容系统、全面，出版周期较长；已逐渐与数字类产品融合，但也依然有固定的受众 |

### 音频传播材料｜P13

| 优点 | 缺点 |
|---|---|
| 传播速度快，覆盖面广，不受空间的限制 | 传播的内容稍纵即逝，听众稍不注意便会错过，无法寻找 |
| 对目标人群的文化程度要求较低，可用目标人群熟悉语言进行录制，易在农村普及，使群众感到亲切 | 只有声音，没有图像，不直观生动，听一遍不容易记住 |
| 节目制作简易、方便、迅速；花费少 | 单向传播，针对性差，无法与听众互动 |

- 形态：广播、新媒体音频（可保留、重复、互动）；案例：延庆广播。

### 视频传播材料｜P14

| 优点 | 缺点 |
|---|---|
| 有画面，有声音，直观形象生动，信息丰富 | 设计制作要求高、成本高 |
| 对目标人群的文化程度要求低，受群众欢迎，传播效果好 | 播放时需要播放终端或设备，使用受到一定限制 |
| 播放次数不限，可以单人看也可以多人看，比较灵活 | — |

- 形态：电影、电视、移动视频。

### 实物类传播材料｜P15

| 优点 | 缺点 |
|---|---|
| 信息载体为实物，有一定的实用性，普遍受目标人群的欢迎和喜爱 | 信息量少，设计简单，多为口号式宣传或信息短语；成本较高 |

## 三、设计与评价

### 健康传播信息生成｜P17–P18

| 生成原则 | 内容 |
|---|---|
| 科学性原则 | 信息正确，有科学证据，符合现代医学进展与共识 |
| 适用性原则 | 热点问题，符合目标人群文化水平和阅读能力，避免产生偏见 |

| 生成流程 |
|---|
| 评估受众需求 → 生成信息 → 对信息进行预实验 → 修改完善信息 → 信息的风险评估 |

| 对信息的具体要求 |
|---|
| 信息不宜过多；信息要简单明确；有明确的行为建议；插图具有关联性和自明性；严禁宣传歧视；适宜目标人群的社会文化 |

| 传播原则与要求 | 内容 |
|---|---|
| 原则 | 适用性原则、可及性原则、经济性原则 |
| 要求 | 注明来源、作者、时间、受众、目的、依据 |

### 设计制作流程｜P19–P20

| # | 步骤 |
|---|---|
| 1 | 选定核心信息（信息生成） |
| 2 | 设计初稿 |
| 3 | 预实验 |
| 4 | 修改与定稿 |
| 5 | 制作与生产 |

- 使用 AI 生成素材需要注意的问题：1. 幻觉——虚假生成，需要核对、核查；2. 版权——生成作品要标注 AI 生成；3. 新技术工具——明确目的和用途。

### 材料评价｜P21

一票否决：

| # | 项目 | 例 |
|---|---|---|
| 1 | 政治性错误 | 港澳台地区表述错误，中国人民共和国地图不完整，比例不正确等 |
| 2 | 不尊重文化差异 | 不尊重不同地区不同品种的文化差异和风俗习惯等 |
| 3 | 歧视 | 对社会弱势群体、残疾人等使用歧视性语言或态度等 |
| 4 | 信息错误 | 内容不科学、不准确等 |
| 5 | 主题与内容匹配性差 | 内容与主题、标题不符，或严重偏颇等 |
| 6 | 法律、行政法规禁止的其他内容 | — |

评分指标：

| 指标 | 内容 |
|---|---|
| 内容评价 | 内容正确，有科学依据，主题鲜明，重点突出，有行为指导性，语言通俗易懂，逻辑性强 |
| 制作评价 | 音频、视频、图文、表演等不同，见课堂讨论评分表 |
| 总体评价 | 整体内容科学、设计风格新颖、实际普及性、传播力度高 |

### 常见错误示例｜P25–P30

| 问题 | 说明 |
|---|---|
| 内容正确性要审查 | 甲肝科普漫画的传播链图示与科学表述不一致 |
| 张贴不牢靠 | 用胶带草草粘贴，边角翘起，易脱落 |
| 不方便居民观看 | 宣传栏被栅栏、绿植遮挡，视线与站位受阻 |
| 文字没有校对 | 版面文字未校对，存在错字、漏字 |
| 悬挂位置太高，光线暗，字体小 | 贴于接近天花板处，超出平视范围；室内照明不足；远距离无法辨读 |
| 标语要贴在警示环境中 | 除四害标语应贴病媒孳生地；交通、防溺水横幅应贴道路与水域附近 |

## 五、案例：促进自然分娩的健康教育

### 课题背景｜P31

| 要点 | 内容 |
|---|---|
| 剖宫产的作用 | 人类自然分娩的有益补充，是产科处理高危妊娠、解决难产，降低孕产妇和婴儿死亡率的重要手段 |
| 无指征剖宫产的危害 | 影响母婴健康，特别是增加婴儿日后哮喘、腹泻、肥胖乃至心血管疾病的患病风险 |
| WHO 调查数据 | 2007 至 2008 年中国的剖宫产率高达 46.2%，其中无指征的剖宫产占 11.7%，远高于 WHO 建议 15% 的剖宫产率的水平 |
