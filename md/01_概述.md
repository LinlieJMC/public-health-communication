# 第1讲 概述

## 一、传播与健康传播的定义

### 什么是传播？｜P2

| 字 | 字形 | 拆解 | 本义 |
|---|---|---|---|
| 传 | 甲骨文 | 左边即“人”，右边即“專”，意为转动 | 古人利用驿车一站站转递信件及物品 |
| 播 | 篆文 | 左边是手，右边上米下田 | 一手执器械掀土，一手抓谷种撒入土坑 |

- 传和播的含义是信息的流动，像散播种子一样把信息散布开来。
- 《隋书·北狄·突厥传》《北史·突厥传》：“宜传播天下，咸使知闻”

### 库利的定义｜P3

传播是人类关系赖以存在和发展的机制，是一切心灵符号及其在空间上传递、在时间上保存的手段。

——1909年，美国社会学家查尔斯·库利，《社会组织》中《传播》一章

| 项目 | 内容 |
|---|---|
| 人物 | 查尔斯·库利（Charles H. Cooley），美国社会学家 |
| 时间与出处 | 1909 年，《社会组织》中《传播》一章 |
| 两个维度 | 空间上传递、时间上保存 |
| 落点 | 强调传播的社会关系属性，把传播看作人与人的关系得以成立和发展的基础 |

### communication 与“传播”｜P4

| 词 | 含义 |
|---|---|
| communication | 更加强调双方交换，双向交流 |
| 传播（汉语） | 形象地展示了信息从一方向另一方的单向流动 |
| 共同点 | 通过信息的流动来达到信息的共享 |

- 词源：前缀“com”是“共同，共有”，后半部分是“交换”的意思，合起来意为“共同分享”。
- 考虑到差异，有时也会使用“交流”或“沟通”，尤其在人际传播中。

### 传播的定义｜P5

| 来源 | 定义 |
|---|---|
| 一般定义 | 传播是指人与人之间通过一定的符号进行的信息交流与分享，是人类普遍存在的一种社会行为 |
| 1988 年我国第一部《新闻学字典》 | 传播是一种社会性传递信息的行为，是个人之间、集体之间以及集体个人之间交换、传递新闻、事实、意见的信息过程 |
| 传播学 | 研究人类制作、储存、传递和接受信息等一切传播活动，研究人们之间交流与分享信息的关系的一般规律的学科 |

### 健康传播的定义｜P6

健康传播是传播学的一个分支，也是传播学的组成部分，它是指以“人人健康”为出发点，运用各种传播媒介渠道和方法，为维护和促进人类健康的目的而制作、传递、分散、交流、分享健康信息的过程。健康传播是一般传播行为在医疗卫生领域的具体和深化，并有其独自的特点和规律。

| 拆解 | 内容 |
|---|---|
| 学科定位 | 传播学的一个分支，也是传播学的组成部分 |
| 出发点 | “人人健康” |
| 手段 | 各种传播媒介渠道和方法 |
| 目的 | 维护和促进人类健康 |
| 行为链 | 制作、传递、分散、交流、分享健康信息 |
| 与一般传播的关系 | 一般传播行为在医疗卫生领域的具体和深化 |

## 二、传播的要素与分类

### 传播的要素｜P7

| 要素 | 原文定义 |
|---|---|
| 传播者 | 信息的主动发出者和媒介的控制者。既可以是个人，也可以是群体或组织 |
| 信息与讯息 | 讯息是由一组相关联的信息符号所构成的一则具体的能够表达某种完整意义的信息，是信息内容的实体 |
| 媒介和渠道 | 讯息的载体，传递信息符号的中介。一般特指非自然的电子类、印刷类及通俗类传播媒介 |
| 受传者 | 传播过程中“受”的一端的个体或团体，即讯息的接收者和反应者，传播者的作用对象 |

### 传播的分类｜P8

| 序 | 类型 |
|---|---|
| 1 | 自我传播（人内传播） |
| 2 | 人际传播 |
| 3 | 群体传播 |
| 4 | 组织传播 |
| 5 | 大众传播 |

## 三、传播与健康传播的特性与功能

### 传播与健康传播的特性｜P9

| 特性 | 原文表述 | 原文举例 |
|---|---|---|
| 信息共享活动 | 社会信息的传播具有交流、交换和扩散的性质；健康传播的共享多与健康主题相关 | 每年 5 月 31 日世界无烟日前后，社会上都会广泛地传播与烟草危害健康相关的信息 |
| 社会关系的体现 | 通过传播，人们保持既有社会关系并建立新的社会关系；可能是纵向的，也可是横向的，传受双方表述的内容和采用的姿态、措辞等无不反映其社会角色和地位 | 《健康中国2030规划纲要》的颁布是典型的纵向传播；少数民族地区健康传播 |
| 双向社会互动行为 | 通过信息的传授和反馈实现社会互动；双向性有强弱之分，在人际传播中体现得非常突出，在群体传播中次之，大众传播中会显得更弱一些 | — |
| 借助一定感知觉符号 | 语言符号、音响符号、图画符号、文字符号、表情符号等；双方必须在这些符号上有共通的意义空间，否则传而不通，导致误解 | — |

### 传播与健康传播的社会功能｜P10

| 功能 | 原文表述 | 原文举例 |
|---|---|---|
| 环境监控功能 | “瞭望哨”的作用，帮助人类及时收集和提供关于环境变化的信息 | 突发公共卫生事件中，从个人到国家，都会随时关注相关信息，以便做出正确的决策 |
| 社会协调功能 | 社会各部分的沟通、协调与统一，使社会整体有效地适应内外环境的变化 | 5 月 31 日“世界无烟日”、6 月 26 日“禁毒宣传日”等日期，全社会开展戒烟、禁毒等宣传及有关行动 |
| 文化传承功能 | 传播系统不断完善，前人的经验、智慧、知识被记录、积累、流传下来，后人进一步发展 | 健康知识、经验，人类在与疾病的斗争的总结，实现了传承和发展 |
| 娱乐与教导功能 | 使个人得到娱乐和享受充实精神生活；通过传播媒体介绍和推广健康的生活方式 | 向医生咨询、参加健康大课堂、收看电视《健康之路》、上网搜寻健康信息、App 等 |

## 四、健康传播的发展史

### 中国古代｜P11–P18

健康传播自古有之，因为人类的生存繁衍一直伴随着健康问题，与健康有关的经验不断地被总结和传播，因此以实践为主的健康传播活动历史非常悠久。

| 载体 | 原文内容 |
|---|---|
| 民间谚语 | “冬吃萝卜夏吃姜，不劳医生开药方” |
| 西方谚语 | “An apple a day keeps the doctor away” |
| 《黄帝内经》 | “圣人之治病也，必知天地阴阳，四时经纪，五脏六腑，雌雄表里。刺灸砭石，毒药所主，从容人事，以明经道，贵贱贪富，各异品理，问年少长，勇惧之理，审于分部，知病本始，八正九候，诊必副矣。”——《黄帝内经·素问·疏五过论》第七十七篇 |

| 配伍口诀 | “藻戟遂芫具战草”——甘草与大戟、芫花、甘遂、海藻相克 |

### 美国健康传播的起源与发展｜P27

一般认为美国是现代健康传播学科的发源地，美国从 20 世纪 60 年代起将传播学引入健康教育领域，并逐渐形成了健康传播学。

| 年份 | 原文内容 |
|---|---|
| 1971 | 1971–1975 年美国斯坦福大学开展以社区为基础的健康促进运动，即“斯坦福心脏病预防项目”（SHDPP），成功运用了社会认知理论、创新扩散理论和社会营销策略 |
| 1972 | 国际传播学会（ICA）成立“治疗传播兴趣小组”，是传播学者开始关注健康领域的起点 |
| 1975 | ICA 将该小组更名为“健康传播分会”，“健康传播”这一名称正式进入学术界 |
| 1984 | 第一本健康传播研究领域专业书籍《Health Communication: Theory and Practice》出版，最具里程碑意义 |
| 1985 | 美国成立“健康传播委员会” |
| 1989 | 创办《Health Communication（健康传播）》季刊，侧重理论性研究 |
| 1996 | 创办《Journal of Health Communication（健康传播杂志）》，侧重国际性、应用性研究 |

### 中国健康传播的起源与发展｜P28–P29

| 1987 | 我国首届健康教育理论学习研讨会在北京举行，会上第一次系统地介绍了传播学理论在健康教育中的应用 |

| 1990 | 20 世纪 90 年代初，北医、华西、同济、上医、中山、河北职工医学院率先开设了健康教育学、健康传播学相关课程 |
| 1993 | 爱国卫生运动委员会办公室组织专家编写健康教育教材，其中之一为主编单位为北京医科大学的《健康传播学》，成为我国第一本健康传播方面的专业书籍 |
