## 7.2 人际传播概述

### P4｜连 246 人际传播的定义

**原文照录**

> p人际传播也称人际交流，是指人与人之间进行最直接信息沟通
> 的一类交流活动。这类交流主要是通过语言来完成，也可以通
> 过非语言的方式来进行，如动作、手势、表情、信号（包括文
> 字和符号）等。
> 一、概念

**讲解**

| 要素 | 原文 |
|---|---|
| 别称 | 人际交流 |
| 定义 | 人与人之间进行**最直接**信息沟通的一类交流活动 |
| 主要方式 | 语言 |
| 辅助方式 | 非语言：动作、手势、表情、信号（包括文字和符号）等 |

- “最直接”是人际传播区别于大众传播的关键限定。

### P14｜连 256 言语行为理论

**原文照录**

> p言语行为理论(Speech Act Theory)的概念是由英国哲学家奥斯汀
> （J.L.Austin）于1962年在其著作《如何以言行事》中提出。
> p言语行为理论的核心原则是：任何一个言语行为都由三个“次行为”构成：
>   言内行为(locutionary act)：指交际过程中说话者话语的字面意思
>   言外行为(illocutionary act)：指说话人的交际意图
>   言后行为(perlocutionary act)：指说话者的交际意图被听话者领悟后可能
> 产生的影响或效果以及听话者可能的行为反应
> p了解对方的性格特点、所处情境等
> 言语行为理论

**讲解**

| 项目 | 内容 |
|---|---|
| 提出者 | 英国哲学家奥斯汀（J. L. Austin） |
| 时间／著作 | 1962 年，《如何以言行事》 |
| 核心原则 | 任何言语行为都由三个“次行为”构成 |

| 次行为 | 英文 | 定义（原文） |
|---|---|---|
| 言内行为 | locutionary act | 交际过程中说话者话语的**字面意思** |
| 言外行为 | illocutionary act | 说话人的**交际意图** |
| 言后行为 | perlocutionary act | 交际意图被听话者领悟后可能产生的**影响或效果**，以及听话者可能的行为反应 |

- 应用前提（原文）：了解对方的性格特点、所处情境等。

### P16｜连 258 听的技巧

**原文照录**

> 听的技巧
> • 认真听完对方表述，不轻易打断对方；
> • 准确获取并记住信息
> • 理解患者说的话对患者来说意味着什么

**讲解**

|---|---|
| 行为层 | 认真听完，不轻易打断；听时不被其他事情干扰 |
| 信息层 | 准确获取并记住信息 |
| 意义层 | 理解患者说的话对患者来说意味着什么 |

### P20｜连 262 违背期望理论

## 本讲速查表

| 主题 | 必记内容 |
|---|---|
| 定义 | 人际传播＝人与人之间进行最直接信息沟通的交流活动；主要靠语言，也可用非语言（动作、手势、表情、信号） |
| 形式 | 个人之间／个人与群体之间／群体与群体之间 |
| 场景 | 个体—医患沟通（入户调查、问诊、现场调查、演示、咨询、劝服）；小群体—患者健康教育（讲座、演示、同伴教育、小组学习）；大众—公众健康教育（义诊、公众咨询、社区讲座） |
| 五个特点 | 不需非自然媒介；信息意义丰富复杂（易“走样”）；双向性强、互动及时、效果可控；双方互为传者受者；覆盖面有限、保存复制能力差 |
| 三大功能 | 社会协作、行为调整、心理保健 |
| 六项技巧 | 说话、倾听、提问、反馈、身体语言、时空语；以信任为基础 |
| 说话六条 | 用能懂的词、术语要解释、吐词清晰、语气亲切、中性客观、适当重复 |
| 言语行为理论 | 奥斯汀 1962《如何以言行事》；言内（字面）／言外（意图）／言后（效果与反应） |
| 听 | 听完不打断、准确获取、理解对患者的意义、表示在听、不受干扰、听话外音 |
| 提问六类 | 封闭、开放、试探、索究、倾向（应避免）、复合（应避免） |
| 反馈四类 | 肯定性、否定性（先肯定再建议）、鞭策性、体语 |
| 非语言七项 | 体势、目光、衣着、声调、时间、礼物、微笑 |
| 违背期望 | 布根与琼斯 1976；布根与黑尔 1988；期望含距离、语速、音量、注视、触摸；不越界（物理与心理） |
| 效果定义 | 受传者接受信息后在情感、思想、态度、行为上的反应 |
| 五环节 | 传播者（把关人）→信息（符号共识）→媒介渠道（可及性、组合）→受传者（选择性注意／理解／记忆）→效果；反馈回路 |
| 效果四层次 | 知晓健康信息 → 健康信念认同 → 态度转变 → 采纳健康行为与生活方式 |
