# 第7讲 人际传播与效果

## 一、人际传播概述

### 概念｜P4–P6

人际传播也称人际交流，是指人与人之间进行最直接信息沟通的一类交流活动。这类交流主要是通过语言来完成，也可以通过非语言的方式来进行，如动作、手势、表情、信号（包括文字和符号）等。

| 项目 | 内容 |
|---|---|
| 地位 | 一种最典型的社会传播活动，也是人与人社会关系的直接体现 |
| 三种形式 | 个人之间、个人与群体之间、群体与群体之间 |

### 医疗卫生中的沟通交流｜P7

| 对象 | 场景 | 具体形式 |
|---|---|---|
| 个体（患者或调查对象） | 医患沟通 | 入户调查、问诊、现场调查、演示、咨询、劝服 |
| 小群体（患者或调查对象） | 患者健康教育 | 讲座、演示、同伴教育、小组学习 |
| 社会大众 | 公众健康教育 | 义诊、公众咨询、社区讲座 |

- 与他人的沟通交流，但人内传播（自我传播，自我沟通）是与他人沟通交流的基础。

### 人际传播的特点｜P8–P9

| 特点 | 原文表述 |
|---|---|
| 不需要任何非自然的媒介 | 不受机构、媒介、时空等条件的限制；运用表情、眼神、动作等多种渠道或手段；在媒介使用还不够普及、不够方便的广大偏远农村，人际传播往往是主要的传播策略 |
| 信息的意义更为丰富和复杂 | 表情等多种渠道和多种手段配合，形成新的传播情境；在多级的人际传播活动中，信息容易“走样”；注意对传播者的培训；不同文化背景 |
| 双向性强，互动及时，效果可控 | 随时根据对方的反馈把握和调整自己的传播效果；高质量的传播活动，尤其在说服和沟通情感方面；健康教育人员应随时调整传播技巧 |
| 传播双方互为传播者、受传者 | 双方在传播过程中都既传送信息，同时也接受来自外部的新信息和来自对方的反馈信息；健康教育工作者不仅要掌握传播信息的技巧，而且也需要掌握接受信息的技巧 |
| 覆盖面有限、保存复制信息能力差 | 信息量比较少，覆盖的范围比较小；传播的速度比较慢；不借助媒介或传播材料进行的面对面交流中，信息不易保存，更不能复制 |

### 人际传播的功能｜P10

| 功能 | 原文表述 | 例 |
|---|---|---|
| 社会协作功能 | 人的社会属性；医者和患者不断地交流互动，共同制定“医”“患”双方同意的诊疗方案；社区健康管理人员与居民共同制定慢病干预计划 | 医生与患者、保安与居民、疾控人员与患者、学生与老师 |
| 行为调整功能 | 群体内部个体之间行动上的协调默契、和谐统一；同伴教育，同伴支持，家庭支持，社会支持 | 口罩使用、洗手、通风；公共场所不吸烟；疫苗接种；核酸检测、健康码使用 |
| 心理保健功能 | 人际传播对于人们心身健康具有保健作用；引导人们善于识别抵制不健康信息和概念，善于化解不良情绪，注重心理卫生，促进人们采纳有利于健康的行为和生活方式 | 倾诉压力与焦虑；热线咨询工作带来的压力 |

### 说话技巧｜P13

| # | 要求 |
|---|---|
| 1 | 用患者“能懂”的词汇、语言 |
| 2 | 使用专业词汇时，做必要的解释、举例 |
| 3 | 发音吐词要清晰，要让对方能够听清楚 |
| 4 | 语气和蔼、亲切 |
| 5 | 使用中性词，客观；避免刺激、恐吓 |
| 6 | 适当重复重要的和不易被理解的话 |

### 言语行为理论｜P14

言语行为理论（Speech Act Theory）的概念是由英国哲学家奥斯汀（J.L.Austin）于 1962 年在其著作《如何以言行事》中提出。核心原则是：任何一个言语行为都由三个“次行为”构成。

| 次行为 | 英文 | 定义 |
|---|---|---|
| 言内行为 | locutionary act | 指交际过程中说话者话语的字面意思 |
| 言外行为 | illocutionary act | 指说话人的交际意图 |
| 言后行为 | perlocutionary act | 指说话者的交际意图被听话者领悟后可能产生的影响或效果以及听话者可能的行为反应 |

- 了解对方的性格特点、所处情境等。

### 社会现实的等级结构｜P15

| 层级 | 示例 |
|---|---|
| 原始信息向意义转换的第一步 | 医生对一位患者说“相信我”，患者：好哒 |
| 通过说话而执行的行为 | 同上 |
| 两个处于一定关系中的人存在的默认协定 | 医患关系的默认信任 |
| 有确定的开端、发展和结局的惯例 | 复杂情景，在三甲医院要排队，要等床，检查结果不好 |
| 用来协调意义的过去的或现在的情节片段 | 患者是之前的老患者，经常来看病 |
| 人们倾向于认同特定文化中的特定群体 | 患者周边的亲人朋友以及自己的看病经历 |
| 社会现实的体系 | 医者仁心，伤医事件，红包等 |

- 不同情境，不同传受双方会体现出不同层级的影响。

### 听的技巧｜P16

| # | 要求 |
|---|---|
| 1 | 认真听完对方表述，不轻易打断对方 |
| 2 | 准确获取并记住信息 |
| 3 | 理解患者说的话对患者来说意味着什么 |
| 4 | 表现出你专心听，并努力理解对方 |
| 5 | 听对方讲话时不被其他事情干扰 |
| 6 | 持友好和礼貌，利用“嗯”“哦”“是吗”等语言和“点头”“微笑”等非语言表示在认真听 |
| 7 | 对敏感的问题，更要善于听出话外音，以捕捉真实的信息 |

### 提问技巧｜P17

| 类型 | 提问方式 |
|---|---|
| 封闭型问题 | 几个？是否？ |
| 开放型问题 | 是什么？怎么看？ |
| 试探型问题 | 可否？能不能？ |
| 索究型问题 | 为什么？ |
| 倾向型问题 | 存在权威/群体压力、诱导的问题 |
| 复合型问题 | 两个问题放在一起 |

### 反馈技巧｜P18

| 类型 | 定义 |
|---|---|
| 肯定性反馈 | 对谈话对方的正确言行表示赞同或支持：是的；对的；进步很大；这是正确的…… |
| 否定性反馈 | 对对方的不正确言行或存在问题提出否定性意见；先肯定，再提建议，让对方易于接受 |
| 鞭策性反馈 | 提出更高的要求或激励 |
| 体语反馈 | 可以配合上述情况，也可以单独进行：点头、手势、抚触、摇头、面部表情 |

### 违背期望理论｜P20

违背期望理论（Expectancy Violation Theory）是由布根（Burgoon）和琼斯（Jones）于 1976 年最先提出的一种非言语行为理论。该理论早期最完整的陈述是由布根（Burgoon）和黑尔（Hale）于 1988 年提出的。违背期望理论的中心原则是，我们都应该对或将会对互动有什么样的期望。

| 要点 | 内容 |
|---|---|
| 期望内容 | 活动过程中的距离、语音语速、音量、眼睛注视、触摸和其他许多行为；不能越界（物理距离和心理距离） |
| 研究焦点 | “期望”探究的是互动中的实际行为；“期望”在不同社会规范和特质差异间表现不同 |
| 应用提醒 | 抚摸能缓解人的紧张情绪，在医患沟通中也要注意不同的情境和对象：男医生与女患者；一般门诊与交通事故现场 |

### 应答与沟通的技巧要点｜P22

| # | 要点 |
|---|---|
| 1 | 倾听：对对方提出的问题要给予高度重视 |
| 2 | 与听众保持良好关系：用积极态度，耐心解答，并确认自己的回答是否让对方满意 |
| 3 | 澄清问题：仔细分析，若有疑问，请提问者再重复一遍 |
| 4 | 耐心解答：考虑提问者的背景和知识层次、知识结构，尽量避免用专业术语 |
| 5 | 敏感问题：可以暂时回避，不做正面解答 |
| 6 | 知识性问题和决策性问题：不给予似是而非的回答 |
| 7 | 对方的正确观点和行为：明确支持，点头等 |
| 8 | 非语言：点头表示肯定，摇头表示否定；微笑、握手表示友好；亲切的目光表示尊重；服饰整洁，仪表端庄；改变声调节奏，合理运用笑声 |

## 三、影响传播效果的因素

### 传播效果的定义｜P24

效果是指受传者接受信息后，在情感、思想、态度、行为等方面发生的反应。

### 传播者｜P25

| 项目 | 内容 |
|---|---|
| 类型 | 个人：医生、讲演者、节目主持人、教师等；团体：报社、电台、电视台等 |
| 把关人 | 指在信息传递过程中，进行信息选择和信息取舍，决定向受众提供哪些信息的人 |
| 要求 | 提高专业素质，发挥把关人作用；树立良好形象，提升公信力；贴近受众生活，增加共同语言 |

### 信息｜P26

| 要点 | 内容 |
|---|---|
| 信息 | 泛指情报、消息、数据、信号等有关周围环境的知识 |
| 符号 | 文字、语言、语气、动作、图形、声音、色彩…… |
| 基础 | 对符号的共识是实现沟通的基础 |
| 要求 | 信息表达形式要与内容相匹配，并且能够被受传者理解、接受 |
| 方式选择 | 根据受众特点和需求，选择合适的方式：理与情、正与反、大众与个性、说教与讨论 |

### 媒介渠道｜P27

| 要点 | 内容 |
|---|---|
| 定义 | 是讯息的载体，传递信息符号的中介、渠道 |
| 类型 | 电子类、印刷类，如书刊、杂志、报纸、广告牌、收音机、电视机、光碟、计算机及互联网、手机等 |
| 要求 | 要考虑受众对媒介渠道的可及性；多种渠道与信息表现形式组合运用 |
| 概念 | 全媒体：各种媒体的特点 |

### 受传者｜P28

| 要点 | 内容 |
|---|---|
| 定义 | 在传播过程中“接受”的一端的个体或团体的总称 |
| 属性 | 既有被动性，又有主动性 |
| 选择性 | 选择性注意、选择性理解、选择性记忆 |
| 心理特征 | 希望获得真实可信、科学、实用的信息；喜欢新颖、有趣的形式；简单易懂；参与地点近，交通方便 |
| 个人情况 | 年龄、性别、职业、教育程度、收入、民族 |
| 健康状况 | 是否患病及严重程度 |
| 社会环境 | 风俗、所属团体、社会氛围、宗教信仰 |
| 自然环境 | 天气、地理环境、设备情况、场所 |

### 反馈｜P29

反馈：传播者获知受传者接受信息后的心理行为反应。及时地反馈是使传播活动生动活泼地进行下去的重要条件。反馈越及时、越充分、越准确，则越有利于传受双方的信息沟通。

- 两种获取方式：直接获得受传者主动反映的情况（观察，阅读量等）；传播者运用反馈机制去收集受传者对信息的被动反应（调查、监测等）。

### 健康传播效果的层次｜P30

| 层级 | 内容 |
|---|---|
| 1 | 知晓健康信息 |
| 2 | 健康信念认同 |
| 3 | 态度向有利于健康的方面转变 |
| 4 | 采纳健康的行为和生活方式 |
