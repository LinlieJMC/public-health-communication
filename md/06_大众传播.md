# 第6讲 大众传播

## 一、概念

### 大众传播｜P3

大众传播（Mass communication）是指运用大众传播媒介，以社会大众为主要传播对象而进行的信息传播活动。大众传播的传播者是有一定规模的传媒组织及其记者、策划、编辑等从业人员，如报社、电视台、广播电台等。

### 大众健康传播｜P4

| 概念 | 定义 |
|---|---|
| 大众健康传播 | 运用大众传播媒介，制作、传递、分享健康信息，改善人们与健康有关的意识、观念和行为，减少或控制健康危险因素，预防疾病，保护和促进健康的过程 |
| 广义 | 凡是能对人们的健康产生直接或间接影响的大众传播活动 |
| 狭义 | 有计划、有目的地运用大众传媒开展的健康传播活动 |

## 二、媒介与传播特点

### 大众传播媒介的分类｜P5

| 类别 | 媒介 |
|---|---|
| 纸媒 | 报纸、杂志、图书 |
| 电子媒介 | 广播、电影、电视 |
| 其他 | 广告、戏曲、音乐、折纸…… |

- 技术的发展直接影响传播媒介的变化。

### 媒介特点｜P6

| 媒介 | 特点 |
|---|---|
| 报纸 | 纸媒代表，便于携带，曾经是新闻的主要来源 |
| 杂志 | 固定出版，读者群固定，可承载较多信息内容和形式 |
| 图书 | 内容系统、全面，出版周期较长 |
| 广播 | 传播迅速，覆盖面广，不受时空限制，经济方便，有固定播出时间限制 |
| 电影 | 是多种形式的综合体，成本较高，制作周期长且复杂 |
| 电视 | 集合了报纸、广播和电影的功能，时效性强，可直播，直观易懂 |

### 大众传播的特点｜P7–P8

| 特点 | 原文表述 |
|---|---|
| 传播活动的组织化和专业化 | 以报社、杂志社、电视台、电台以及影像制作机构等大众传播媒介为平台，传播效率高 |
| 受众的广泛性 | 传播的对象分散、广泛且不确定，其受众是普通大众，不分群体和阶层；受众对健康传播存在一定的选择性，只有被受众注意到或选择的信息，才能对受众产生影响 |
| 传播速度快 | 借助被广泛普及的大众媒介，信息扩散速度快 |
| 单向传播，缺乏反馈 | 信息流向呈单向性，可以很容易地通过大众健康传播获取健康信息，但不能及时收到反馈信息，不利于健康传播效果的评估 |

## 三、媒介选择与讯息策略

### 媒介选择原则｜P10

| 原则 | 内容 |
|---|---|
| 有效性原则 | 是否有活动开展的经验、成功案例、有哪些效果 |
| 针对性原则 | 不同媒介有各自不同的信息传播方式，应根据目的和目标、人群特点、需求和媒体偏好 |
| 可及性原则 | 不同媒介在当地的覆盖情况和受众的使用习惯，避免选择目标受众不易接触到的媒介 |
| 成本效益原则 | 社区和公众人数较多，应选择成本相对低而社会效益和经济效益都比较高的媒介 |
| 综合性原则 | 提供与健康信息相关的多种服务和产品，多种媒介共同使用，有利于健康行为的形成或转变 |

### 讯息策略（一）｜P11

| 策略 | 做法 |
|---|---|
| 吸引注意力 | 运用视觉材料和不同的语音风格 |
| 重点突出 | 直接呈现结论，最强力的观点开始，忌平铺直叙 |
| 信息清晰明确 | 很容易搞清楚应该怎么做，为什么，以及这样做的效果，可以使用统计数据（科学严谨） |
| 推荐行为简单易行 | 难度太大不容易被受众接受，应有较少的障碍和循序渐进的过程 |
| 有效使用激励物 | 受众感兴趣的内容，提供物质的、心理的或经济的激励物 |
| 提供确凿证据 | 说明推荐的行为能减少疾病、伤害或死亡的威胁，并向不同的受众提供不同类型的证据 |

### 讯息策略（二）｜P12

| 策略 | 做法 |
|---|---|
| 信息来源可靠 | 信用度受到权力、专业水准、忠诚度、吸引力和与受众的相似程度的影响 |
| 信息值得信赖 | 真实，不采用极端的说法或例子，不使用戏剧性或夸张成分的讯息 |
| 调门适中 | 适合目标受众接受的语气，避免祈求，也不能强迫 |
| 满足诉求 | 对感兴趣的受众，使用理性诉求有效；对于不感兴趣的受众，可使用感性诉求，激发兴趣 |
| 避免冒犯性信息 | 不让受众感到被伤害或被冒犯，行为的产生很复杂，应考虑到行为产生的背后原因（文化、宗教等） |
| 展示符号 | 展示身份信息（传播者、机构等的名称、职能、标识、口号、形象等），显著增强传播效果 |

### 受众差异与知识沟｜P13–P14

| 差异维度 | 例 |
|---|---|
| 性别 | 体重管理（男生与女生） |
| 年龄 | 营养保健品（年轻人与老年人） |
| 城乡 | 媒介使用（城市与偏远山区） |

蒂奇纳等人于 1970 年提出“知识沟”的概念，认为因为人们接触传播媒介的机会和条件不同，大众传播实际上会扩大社会不同阶层成员间的知识差距，称为“知识沟”假说。

- 经济状况好的人比经济状况差的人更容易获取信息，会接受更多的教育，对某些问题有预先了解或更深入了解。
- 知识沟也存在于不同政治倾向、不同年龄的人群之间，不仅仅是知识的差距，也可能涉及态度和行为，以及对于媒介的使用。

### 使用与满足理论｜P15

| 对比 | 传统传播理论 | 使用与满足理论 |
|---|---|---|
| 受众地位 | 受众是被动的 | 受众根据自身的“需求”接触或选择媒体，并通过接触和选择特定的媒体使自己的特定需求和动机得到“满足” |
| 媒介作用 | 媒介发挥说服受众的主导作用 | 受众通过选择、使用、满足的过程也会对媒体造成影响 |

- 现代使用与满足理论：人们使用媒介的目的都是满足自己的需要；接触和使用媒介要具备 2 个条件，即可及性和媒介印象；对媒介是否能够满足自己需求的评价决定了他今后对媒介的接触和选择。
- 应用：在老年人群体中使用电视栏目进行宣传；在大学生中用新媒体形式进行宣传。

## 四、大众健康传播的应用

### 新闻健康传播｜P17

新闻：有关新近发生的事实的报道。新闻健康传播：指通过健康议程设置，运用新闻报道，影响人们的健康相关态度、观念和行为的传播活动。

| # | 报道类型 |
|---|---|
| ① | 有关卫生政策方针、策略规划、健康保障、健康服务等方面的新闻报道 |
| ② | 医疗卫生行业人物、事件、工作进展的信息报道 |
| ③ | 与疾病治疗相关的方案、技术、服务等有关信息的报道 |
| ④ | 对影响人们健康的社会事件信息的报道，如环境污染、气候变化、工程施工、道路安全、食品卫生与安全等 |

### 媒体健康倡导｜P18

媒体倡导（media advocacy）是指通过大众新闻媒体引导公众舆论，动员社区中的积极分子，影响决策者，从而促使有关政策进行调整或改变的过程。媒体倡导活动仅指利用新闻媒体开展的倡导活动。

| 优势 | 内容 |
|---|---|
| ① | 媒体倡导的议题是公共健康问题 |
| ② | 是通过与媒体沟通达成共识，而不是靠付费的商业广告 |
| ③ | 一旦形成公共政策，会对广大公众造成长期、持久和广泛的影响 |

- 议题：环境污染、吸烟、沙尘暴、气候变化、垃圾分类……

### 艺术作品健康传播｜P19

以健康为题材的艺术作品，通过叙事的方式，让人们在欣赏曲折动人的故事、感受艺术之美的同时，受到健康知识的沐浴和健康文化的熏陶。在艺术作品中巧妙融入健康元素。

- 形式：电影、电视、歌曲、广告、舞蹈、文学、名人等。

### 健康中国行动：健康知识普及行动｜P20

- 每年 6 月为健康素养宣传月，9 月为全民健身生活方式宣传月，健康主题宣传日（艾滋病、结核、控烟、爱牙等）。

| 板块 | 专项行动 |
|---|---|
| 全方位干预健康影响因素 | 健康知识普及行动、合理膳食行动、全民健身行动、控烟行动、心理健康促进行动、健康环境促进行动 |
| 维护全生命周期健康 | 妇幼健康促进行动、中小学健康促进行动、职业健康保护行动、老年健康促进行动 |
| 防控重大疾病 | 心脑血管疾病防治行动、癌症防治行动、慢性呼吸系统疾病防治行动、糖尿病防治行动、传染病和地方病防控行动 |

- 主要指标：居民健康素养水平基期 14.22%，2022 年目标 ≥22%，2030 年目标 ≥30%（预期性）。
