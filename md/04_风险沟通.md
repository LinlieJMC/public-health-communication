# 第4讲 风险沟通

## 一、风险与危机

### 风险（risk）的定义｜P4

| 表述 | 内容 |
|---|---|
| ① | 损害或损失的机会或可能性 |
| ② | 损失的不确定性 |
| ③ | 在给定情况下和特定时间内，那些可能发生的结果之间的差异 |
| ④ | 负面效应出现的几率或者导致负面效应的某一因素（risk as a probability of an adverse outcome, or a factor that raises this probability）→ 流行病学中的病因 |

- 公共卫生的重点应转向风险管理：全球大量的疾病和死亡都是由一系列可改变的风险因素造成的；公共卫生工作的核心应该是识别、评估并优先处理那些可预防的、影响最大的风险因素。
- 特征：面向未来，可测量，可控性。
- 出处：世界卫生组织，2002，The World Health Report 2002 – Reducing Risks, Promoting Healthy Life。

### 风险的特点｜P5–P7

| 特点 | 内容 | 例 |
|---|---|---|
| 普遍性、多样性 | 风险无处不在 | 2008 年汶川地震、2011 年福岛核泄漏、2020 年贝鲁特港口爆炸、非洲埃博拉疫情、席卷全球的 COVID-19 疫情、2026 年“8.26”西藏吉隆泥石流灾害 |
| 不确定性 | 损害是否发生、损失有多大、导致哪些损害、损害何时发生 | — |

| 结局 | 含义 |
|---|---|
| 0 未发生 | 风险一直存在 |
| 1 发生 | 危机事件 |

### 公共卫生视角的三类危机｜P8

| 类型 | 成因 | 后果 |
|---|---|---|
| 事件危机 | 重大公共卫生事件导致的危机 | 健康、生命、心理，社会稳定、经济 |
| 机构危机 | 机构失误、人员履职不当给机构带来危机 | 机构声誉、形象、公信力受损 |
| 舆情危机 | 媒体广泛传播卫生健康信息引发的公众过激反应 | 公众健康损失、机构形象受损 |

## 二、风险沟通的概念

### 定义｜P20

风险沟通是个体、群体以及机构之间交换信息和看法的相互作用过程；这一过程涉及多侧面的风险性质及其相关信息，它不仅直接传递与风险有关的信息，也包括表达对风险事件的关注、意见以及相应的反应，或者发布国家或机构在风险管理的政策和措施等。——美国国家科学院

### 功能与意义｜P21

“过去的五年里，我们在控制疾病暴发方面取得了巨大成功，但是我们直到最近才认识到，对于疾病暴发控制来说，风险沟通和实验室分析以及流行病学调查一样关键”。——世界卫生组织总干事李钟郁博士，2004年9月

应急风险沟通可以避免以下不良行为或影响：

| # | 内容 |
|---|---|
| 1 | 过度医疗 |
| 2 | 不理性的公众行为（如疯狂抢购、家庭过度消毒等） |
| 3 | 采用不当手段获取医疗服务 |
| 4 | 不必要的旅游限制 |
| 5 | 对卫生部门的建议和措施提出质疑 |
| 6 | 对医疗服务的担忧 |
| 7 | 对政府措施的质疑 |
| 8 | 小道消息、谣言铺天盖地 |

### 信息流行病（infodemic）｜P22–P23

An infodemic is too much information including false or misleading information in digital and physical environments during a disease outbreak. It causes confusion and risk-taking behaviours that can harm health. It also leads to mistrust in health authorities and undermines the public health response.

- 中文定义：信息流行病是指在疾病爆发期间，在数字和物理环境中提供了过多的信息，包括虚假或误导性信息；后果是危害健康、公信力挑战、破坏应对措施。
- 出处：1st WHO Infodemiology Conference。
- 与流行病中的病原体一样，信息过量、错误信息传播会导致人们的焦虑、困惑、不信任，增加了卫生应急反应的复杂性；将传统流行病学原理应用于信息领域。

| 类型 | 事实 | 意图 |
|---|---|---|
| Misinformation | 否 | 善意 |
| Disinformation | 否 | 恶意 |
| Malinformation | 是 | 恶意 |

- 专家共识往往会随着时间推移而发生改变，这使得定义“真实”与“虚假”存在潜在的不稳定性或不确定性。

## 三、风险认知

### 风险沟通在沟通什么｜P24

| 项目 | 内容 |
|---|---|
| 目的 | 降低认知差，目标人群的合理认知和合理行为 |
| 实现路径 | 合理认知 → 合理行为 |
| 基础概念 | 风险认知 |

### 专业人员与公众的差异｜P27

| 主体 | 活动 | 特征 | 依据 |
|---|---|---|---|
| 专业人员 | 风险识别 | 客观、理性 | 以数据、实施为依据 |
| 公众 | 风险认知 | 主观、感性 | 受情绪情感因素影响 |

- 风险 ＝ 发生概率 × 后果严重性。
- 风险的认知可能与事实相差甚远。

### 风险认知的定义｜P28

| 来源 | 定义 |
|---|---|
| Slovic，1992（美国） | 风险认知用来描述人们对风险的态度以及对风险的直接判断 |
| 谢晓非，1996 | 风险认知是个体对外界环境中的各种客观风险的主观感受、经验和认识 |
| Perception of risk | 指个体对存在于外界环境中的各种客观风险的感受和认识，包括对某个特定风险特征和严重性做出的主观判断，来源于个体直观判断和既往经验 |

- 风险感知不做特别区分。

### 风险认知与行为｜P29

- 风险认知是公众采取应对行为的基础；风险认知越高，采取行为的力度越大。
- 风险认知过高或过低都不利于合理行动，公众应保持适度风险认知，采纳合理的行动。

### 影响风险认知的因素｜P30

| 类别 | 因素 |
|---|---|
| 风险性质 | 事件发生概率与造成的伤害（飞机失事 vs 车祸伤害）；事件是否突发（地震灾害 vs 环境污染）；自然灾害 vs 人为祸患 |
| 个人因素 | 人口特征（性别、年龄、文化）；健康素养水平；情绪情感（稳定 vs 愤怒；信任与否）；心理倾向（风险涉及人群：儿童 vs 成人、他人 vs 自己） |
| 风险沟通因素 | 风险信息发布的及时性；准确性；发布者（权威性、信任度、口碑等）；回应百姓关切；环境因素（文化、社会认知、群体效应等） |

### 风险认知理论｜P31–P32

| 理论 | 原文表述 |
|---|---|
| 风险认知论 | 关注人们如何感知风险；人们认为对风险缺乏了解、风险暴露不公平、不能及时加以控制，会出现焦虑等负面情绪、引发不理智行为 |
| 信任决定论 | 人们存在负面情绪时，更容易产生对信息的不信任；长期的信任关系有助于进行风险沟通 |
| 心理干扰理论 | “危机＝风险＋愤怒”；风险沟通不仅关注风险，更要关注负面情绪压力下产生的聆听和理解信息困难 |
| 负面优势理论 | 人们对负面信息更敏感，关注度更高，记忆更持久，反应更强烈；负面消息 : 正面消息 ＝ 1 : 3 |

信任的三个维度：

| 维度 | 追问 |
|---|---|
| 动机 | 危机应对者是否着眼于保护我和我家人的健康？ |
| 诚实 | 危机应对者是否隐瞒了信息？ |
| 能力 | 应对者是否有能力控制疫情？ |

### 拟态环境理论｜P34–P35

拟态环境（pseudo-environment）理论由美国政治家李普曼提出。拟态环境又称为“似而非环境”，是指大众传播活动形成的信息环境，并不是客观环境的镜子式的再现，而是大众传播媒介通过对新闻和信息的选择、加工和报道，重新加以结构化以后向人们所提示的环境。

- 大众传媒构建的“拟态环境”，是塑造公众“风险认知”的最主要来源。
- 媒体对某个风险事件报道的频率、角度和情感基调，会直接影响公众对该风险的“可得性”和“恐惧程度”，从而塑造出一个与客观统计数据可能完全不同的主观风险图景。
- 双向性：健康的拟态环境和糟糕的拟态环境。
- 媒体通过“议程设置”、树立“意见领袖”、营造“拟态环境”等影响、制约人们的思维和行动。
- 风险沟通是塑造“健康拟态环境”的关键工具；当沟通失败时，扭曲的拟态环境导致社会失序。

### 风险的社会放大效应｜P36–P37

风险的社会放大效应是指多种机制导致的公众感知到的风险有被放大的现象，即公众感知到的风险大于风险的实际情况。

| 形式 | 手法 |
|---|---|
| 过度报道 | 报道量过大；语言问题、画面过度渲染 |
| 选择性风险表述 | 暗示性语言；使用“污名化”词语；煽情的报道手法 |
| 设立“受害方”与“责任方” | 设立“受害者”；设立“责任方” |

### 小结：风险沟通的本质｜P38

风险沟通的本质：不是在真空中传递信息，而是在一个由客观风险、媒体建构、公众心理和社会文化构成的复杂场域中进行的信任管理和意义协商。

| 启示 | 内容 |
|---|---|
| 理解公众 | 必须了解公众如何感知风险，不能只依赖统计数据 |
| 善用媒体 | 要学会与媒体合作，主动设置议程，构建一个更接近真实的“拟态环境” |
| 建立信任 | 所有沟通的基石是信任；在风险出现前就建立长期、稳定的信任关系至关重要 |
| 预警放大效应 | 要警惕微小信号可能通过社会放大效应演变成巨大危机，需做到早发现、早回应、早澄清 |

## 四、风险沟通的五要素

### 1. 沟通什么（what）｜P40–P41

| 内容 | 原文表述 |
|---|---|
| A | 对风险事件的说明与解释，介绍和分析潜在的风险因素，并预测风险事件可能的发展趋势 |
| B | 推介政府的应对举措、展示政府的应对能力和目前为止的成效 |
| C | 针对个体的指导，包括相关知识及个人应该采取的行为建议 |
| D | 有助于建立情感关联的信息，表达关切、同情、支持与帮助 |

- 三条标准：简单、及时；准确、可信；一致、连贯。
- 风险沟通研究专家提示：在告知风险信息的同时，要同时公布三个积极的消息来平衡一个负面的消息。

### 2. 与谁沟通（to whom）｜P42–P43

风险沟通中，需要识别利益相关者，了解他们对信息的需求，并寻找合适的渠道把这些信息传递给他们。一般说来，大众传媒是与公众沟通最快捷也最有效的手段。风险沟通中“对话”的双方主要是政府与目标受众。

| 类别 | 关注的信息 | 人群 |
|---|---|---|
| 第一类 | 危机应对行动的信息 | 先遣急救员、幸存者、公共卫生和医护工作者 |
| 第二类 | 事件安全性和事实真相的信息 | 突发事件可能波及的人群、媒体、幸存者和救援人员的亲属 |
| 第三类 | 事件安全性和能够用来安抚民众的信息 | — |

### 3. 何时沟通（when）｜P44

| 不会向危机发展的迹象 | 向危机发展的迹象 |
|---|---|
| ① 体现出对政府和相关部门的信任 | ① 媒体误报、不够理性 |
| ② 正面报道数量多 | ② 坊间谣言 |
| ③ 有第三方专家的支持 | ③ 网民讨论增多 |
| — | ④ 舆论情绪化，有舆论领袖发出质疑 |

### 4. 经由哪些渠道沟通（channels）｜P45–P46

| 渠道 | 描述 | 适用人群 |
|---|---|---|
| 大众媒体 | 报纸、电视、广播、门户网站、手机短信等，一般以新闻报道的形式沟通信息 | 全人群，包括政府内部系统和社会公众 |
| 社区与场所 | 交通枢纽及公共场所、大中小学校、医院、居民社区等，一般以传单或讲座的形式交流信息 | 普通社会公众，特别是对流动人群比较适用 |
| 人际 | 会议、培训、研讨等政府内部传播渠道；也包括针对一般居民的入户教育、个人咨询等，一般以对话的形式沟通信息 | 会议渠道主要用于政府内部系统或者与学界、企业界沟通，面对面沟通可用于偏远农村地区 |
| 小媒介 | 简报、电子邮件、传单、手册、宣传画，一般以凝练的文字或形象的图画传递信息 | 对于目标公众较为适用 |

突发公共卫生事件中的风险沟通：

| 沟通客体 | 沟通目的和内容 | 沟通方式 |
|---|---|---|
| 政府 | 说明事态进展，争取相关部门支持，协作应对风险 | 请示、报告、简报 |
| 媒体 | 掌握事态话语权，减少传播过程中噪声干扰 | 新闻发布会、新闻通稿、采访 |
| 意见领袖 | 直接触达受众，扩大影响力 | 新闻发布会、媒体通气会 |
| 其他专业机构 | 遏制风险扩大，帮助进行科学决策 | 会议沟通、工作简报 |

### 5. 反馈（feedback）｜P47

及时掌握沟通对象的反馈意见，是风险沟通的重要一环，这也是风险沟通区别于传统线性传播的关键。风险沟通是一种动态的双向行为，而双向的沟通对信息发送者来说应得到充分的反馈。只有风险沟通的主、客体双方都充分表达了对某一问题的看法，才真正具备风险沟通的意义。

## 五、原则与失败原因

### 风险沟通的八项基本原则｜P48

| 原则 | 要求 |
|---|---|
| 提早准备原则 | 制定风险沟通预案 |
| 速度原则 | 及早发布、主动发布 |
| 公开原则 | 面向社会大众 |
| 权威原则 | 发布信息的准确性、科学性 |
| 责任原则 | 维护健康 |
| 以人为本原则 | 满足公众需求 |
| 公众参与原则 | 双向沟通 |
| 共情原则 | 理解公众的恐惧、焦虑和担忧 |

### 不当的风险沟通策略｜P49

| 策略失误 | 机制 |
|---|---|
| 技术术语过多 | 使用大量专业术语（如“基本再生数 R0 值”“气溶胶传播”）会增加认知负荷，让公众感到困惑和疏远，信息无法被有效编码和理解 |
| 信息模糊不清 | 模糊、不精确的指令（如“尽量减少出行”）会带来不确定性，引发猜测和焦虑，成为一种干扰 |
| 引发恐惧却无解决方案 | 过度强调风险的严重性（“恐惧诉求”），却没有提供清晰、可行、有效的应对方案，会直接引发巨大的情绪干扰（恐慌），导致功能失调行为 |
| 信源不可信 | 发布信息的机构或专家本身缺乏公信力，受众会产生“这个信息可信吗？”的怀疑，这种怀疑感本身就是一个持续的干扰源 |

### 成功沟通的五个关键因素与最严重的沟通问题｜P50

| 五个关键因素 | 最严重的沟通问题 |
|---|---|
| 提早计划 | 官员或专家公开发表的意见不一致 |
| 第一时间发布信息 | 信息发布迟缓 |
| 表示理解与同情 | 专制的家长式的态度 |
| 显示权威性和专业性 | 未对谣言与流言及时做出响应 |
| 保持诚恳与开放性 | 未满足公众知情权 |

### 风险沟通的一般流程｜P56

| 模块 | 要点 |
|---|---|
| A 制定风险沟通预案 | 风险沟通监测预警；风险沟通工作机制（部门责任、信息处理与发布）；不同阶段风险沟通目标、要点（内容、方法）；风险监测与评估 |
| B 日常风险沟通 | 健康教育为主；突出风险相关教育；预警信息发布；与媒体信任合作 |
| C 危机事件中的风险沟通 | 发言人制度；接受媒体采访；及时、连续信息发布；与危机事件所处阶段一致；心理危机干预 |
| D 风险沟通评估 | 适宜度（发布时间、发布途径）；足够度（内容满足需求）；风险沟通效果；风险沟通效益；评估是贯穿始终的 |

### 课程总结｜P57

| 三问 | 回答 |
|---|---|
| 风险危机是什么 | 风险（概率）→ 危机事件（事实） |
| 风险管理做什么 | 识别、控制、处置 |
| 风险沟通怎么做 | 目的：合理认知、合理行动；目标人群：公众、媒体、部门领导等；传播主体：政府、媒体、机构、专家；方式：大众、人际、组织、传播；内容：信息、关注、态度、反应、政策措施 |
