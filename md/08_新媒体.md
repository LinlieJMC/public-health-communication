# 第8讲 新媒体

## 一、概述

### 概念｜P4

“新媒体”一词最早由美国哥伦比亚广播电视网（CBS）技术研究所所长 P. Goldmark 于 1967 年提出。新媒体时代是相对于传统媒体而言的，是报刊、广播、电视等传统媒体以后发展起来的、在新技术支撑体系下出现的新的媒体形态，是利用数字技术、网络技术、移动技术，通过互联网、无线通信网、卫星等渠道以及电脑、手机、数字电视机等终端，向用户提供信息和娱乐服务的传播形态和媒体形态。

| 要素 | 内容 |
|---|---|
| 技术 | 数字技术、网络技术、移动技术 |
| 渠道 | 互联网、无线通信网、卫星 |
| 终端 | 电脑、手机、数字电视机 |
| 功能 | 向用户提供信息和娱乐服务 |

### 新媒体特征｜P5–P6

| 特征 | 原文表述 |
|---|---|
| 数字化 | 网络化、数字化的技术影响，是媒体发展的一种高级形式；具有信息量大，内容丰富，图文声像并茂，具有超文本结构，使用方便，检索快速便捷，信息传播速度快、范围广、更新快，且成本低 |
| 互动性 | 使传播者和受众之间的关系发生了一定的变化，促进了受众的主动性，使受众在新媒体活动中的参与性大大加强 |

## 二、新媒体传播的五个变化

### 传播主体｜P10

去中心化，消除了传播者和接受者的界限；每个人都成为潜在的信息发布者。

- 带来的问题：对内容失去控制，造成谣言迅速播散；信息流行病学（Infordemic）——大量的、低质量的信息造成民众的恐慌，并带来对社会的危害行为。

### 阅读习惯｜P11

随时、随地、方便快捷的信息提供方式；人们的阅读习惯从“深阅读”转向“碎片化”。

- 带来的问题：对长文章伴有注意力障碍，不能对健康问题进行全面的、深入的探讨和分析；对碎片化进行集合汇总，可能看到全貌，每一个人的角度和立场都不同。

### 传播平台｜P12

新媒体传播平台数量众多，不同平台的属性不同，用户特征也不同；个性化。

- 带来的问题：各有局限；不能覆盖所有人群，信号覆盖不到的地区，还离不开传统媒体。

### 受众与信息的关系｜P13

既可以通过搜索引擎主动获取信息，也可以通过大数据为其推送。

- 带来的问题：个人信息及隐私保护，运算规则不完善，被强制推送信息（信息茧房）。

### 传播形式｜P14

可以集文字、图像、音频、视频等多种信息表现形式于一体；弹幕；互动区。

- 新媒体的当前最受欢迎形式：短视频、直播；屏幕时间的不断增加对身体健康的影响（身体活动、认知、视力、社会交往等）。

## 三、四类平台

### 微博｜P16

| 特征 | 内容 |
|---|---|
| 连接方式 | 以内容为纽带的社会网络连接，“个人中心”+“内容关联” |
| 移动化 | 传播的移动化（手机） |
| 开放性 | 交流结构的开放性（可转发） |
| 碎片化 | 传播的碎片化 |
| 社交属性 | 信息传播与社交有机结合（评论、关注） |

| 使用动机 | 关注对象 |
|---|---|
| 找到归属感等；及时了解新闻热点；关注感兴趣的内容；获取有用的知识和帮助；分享有用的知识；发表热点事件的评论；认识更多的新朋友；增加与朋友的感情；发现潜在客户机会 | 同学、朋友、同事、亲戚、明星、网络红人、老师/领导、网友、陌生人、行业名人、行业机构/企业 |

- 2026 年第一季度：月活跃用户 5.62 亿，日活跃人数 2.54 亿。

### 微信｜P17

| 属性 | 功能 |
|---|---|
| 传播层级 | 三个层级的贯通（人际传播、群体传播、大众传播） |
| 社交平台 | 朋友圈 |
| 媒体平台 | 公众号，视频号 |
| 营销及服务平台 | 服务、销售、服务号 |

- 2026 年第一季度：微信与 WeChat 合并月活跃用户 14.32 亿。

### APP 传播｜P18

垂直内容的移动化包装；智能手机、平板电脑以及智能电视等设备的第三方应用程序，也称为客户端（新闻客户端、医院、企业等）；央视频，人民网，北医三院等。

| 特征 |
|---|
| 简化获取信息的路径 |
| 固化用户习惯 |
| 垂直化（深度） |
| 一种专业内容 |
| 针对特点应用的功能诉求和移动终端的屏幕特性 |
| 应用商店（平台的提供者和监管者） |

- 用于专项干预活动，发布内容，收集数据，效果评价。

### 移动视频｜P19

在场感、表演与陪伴；新闻直播；社交性直播（网红、草根）；短视频；综合性视频网站；抖音，快手，B站，YouTube 等。

| 特征 |
|---|
| 自拍（留下自己在场的痕迹） |
| 分享展示自己在大事件中的存在 |
| 第一人称视角，不是媒体视角 |
| 展示真实的生活场景（人，动物） |
| 表演（经济、流量、关注、影响力） |
| 寻求关注和认可（自虐、另类） |
| 不需要使用文字（不必须） |
